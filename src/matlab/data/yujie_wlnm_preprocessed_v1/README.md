# Yujie inputs for WLNM_dir_neg

This directory is generated by `src/matlab/software/preprocess_yujie_wlnm.py`. The original Yujie release is read-only and is never modified.

- `original_observed/`: labels from `edge_status_original_grouped`.
- `final_filled_sensitivity/`: labels from final/imputed `edge_status`.
- `manifests/`: all networks plus exact 60%, sweep, and smoke selections.
- `validation/`: verified source hashes, derived MAT hashes, and counts.

Each MAT contains `net`, `observed_negative_mask`, `candidate_mask`, `unresolved_mask`, canonical WLNM `role`, original `yujie_network_role`, `taxonomy`, all-NaN `mass`, and provenance metadata. The orientation is `A(prey,predator)=1`. Provenance includes both original and final `1/0/NA` counts. Missing states are never negative examples.
